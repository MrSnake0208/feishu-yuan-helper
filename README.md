# feishu-yuan-helper

一个用于飞书（AstrBot）的密探和关卡数据同步插件。

## 功能

- 管理员可通过私聊命令触发密探数据同步
- 管理员可通过私聊命令触发关卡数据同步
- 同步请求只发送一次，失败后不会自动重试

## 管理员指令

以下指令会作为普通命令注册到 AstrBot，通过 AstrBot 配置的命令前缀触发（例如 `#`）。
插件会在运行时校验管理员身份，并且仅支持在私聊中使用。

- `#同步密探`：向同步服务发送 `{"schema": "2.0"}`
- `#同步关卡`：向同步服务发送 `{"schema": "3.0"}`

非管理员执行时，插件会返回“权限不足”；在群聊中执行时，插件会提示改用私聊。

## 同步接口

插件向以下地址发送 `POST` 请求：

- `http://192.168.31.66:28793`

请求头包含 `Content-Type: application/json`。运行 AstrBot 的主机需要能够访问该局域网地址。
HTTP 2xx 视为触发成功；其他状态码或连接异常会返回失败信息。

## 开发说明

插件主逻辑位于 `main.py`，测试使用 Python 标准库 `unittest`。

```bash
python3 -m unittest discover -s tests -v
```
